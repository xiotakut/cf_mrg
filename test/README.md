# 海风骑行 · Pelican Cycling Club

原创 SVG 2D 动画：一只戴着头盔、系着围巾的鹈鹕骑车沿海岸前进。

下载 `index.html` 后直接用浏览器打开即可。HTML、CSS、SVG 和 JavaScript 全部内联，无外部图片、字体、第三方依赖或网络请求，无需构建或启动服务器。

- 车轮、曲柄和双脚同步运动，脚部始终跟随踏板。
- 海浪、云朵、路面与花草移动，围巾飘动，鹈鹕轻微起伏并眨眼。
- 支持暂停/继续和 0.5×–2× 速度调节。
- 适配桌面和手机；跟随系统“减少动态效果”设置，默认静止且可手动播放。
- 切换到后台时暂停渲染，返回时平滑继续。

GitHub 文件页面显示源码；下载 HTML 到本地打开即可观看动画。
