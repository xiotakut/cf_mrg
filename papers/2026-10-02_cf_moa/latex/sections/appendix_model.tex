\section{Historical Explicit-Model Validation}
\label{sec:appendix_model}

The adopted A4 component was previously evaluated on 24 virtual parameter/initial-state
profiles, with 12 questions per profile and model configuration. The 288 questions per
configuration use one fixed simglucose model, four fixed actions, and three question
types. The software snapshot is version 0.2.11 at commit
\texttt{a6f6777586c860457a2a1e6cce6d0bd3fd33d1cc} \citep{simglucose}. This is a
conditional tool-execution panel; it is not part of the 6,104 clinical ALL units and is
not the deferred independent confirmation experiment.
