## 1. 论文的中心命题

**推荐题目：CF-MoA: Taxonomy-Guided Benchmarking and Agent Orchestration for Counterfactual Medical Reasoning**

医学系统面对条件变化，需要判断哪些支持应增加、哪些应撤销、哪些候选应重新比较、哪些后果需要推导，以及哪些判断应保持。现有资源按数据集和任务组织，难以从同一功能视角观察这些需求。我们整理已有医学反事实及扰动资源，建立 R1–R5 五类功能体系，保留原题与原生评分构建跨来源 benchmark；在七个系统配置上发现不同操作子集的不足，进而研发对应的 head，并将这些能力组织为 CF-MoA 的五个功能 agent。采用版以输入能力路由和专门的证据处理连接这些角色，在两个骨干的完整 benchmark 上同时改善总体表现、应变与保持。

论文的主要贡献应同时包含 **taxonomy、benchmark、diagnostic evaluation 和 framework**。不是只讲一个后期验证器，也不必把每次研发尝试平均分配正文篇幅。选取最能支持中心命题的完整实验面板，把迭代和补充版本放到相应机制分析或附录。

### 可以直接发展为英文引言的四点贡献

1. **A functional taxonomy for medical counterfactual evaluation.** We organize changes by five target-specific operations—support establishment, support withdrawal, candidate re-comparison, consequence derivation, and judgment preservation—while retaining overlapping labels and the original task contracts.
2. **An auditable benchmark construction pipeline.** We catalogue 26 candidate resources, acquire 15, and trace 55,991 archived comparison records through qualification and sampling to a benchmark of 6,104 units and 13,000 selected judgments from 11 sources.
3. **A diagnostic study across seven medical question-answering configurations.** We expose operation-specific weaknesses and obtain positive terminal-head gains in all 21 system-by-category comparisons across R1–R3.
4. **CF-MoA, a five-operation agent framework with an evaluated sparse instantiation.** The adopted system improves full-benchmark native scores by 10.09 and 12.01 percentage points on two backbones, with complementary evidence from response/preservation pairs and operation-level controls.

“提出五类分类体系”指功能 taxonomy / annotation scheme，不是训练了五个分类器。可以强调统一视角、可追溯构建和功能角色设计；目前没有比较性文献审计支持“世界首个/最大”，不使用这种限定。

### 2.3 论文逻辑链

**来源分散且任务异构 → 用“变化影响具体目标的哪种功能关系”统一描述 → 建立可追溯、保留原生合同的跨来源 benchmark → 七系统展示功能子集上的不足 → 把操作需求落实为专门 head → 用输入能力路由连接五个角色形成 CF-MoA → 全量结果与机制对照检验设计。**

这是根据真实研究形成的解释顺序。实际研发有重叠、回退和后续补审，不包装为一次预注册、从未调整的线性实验。

**构建的技术价值：**区分分类资格与评分资格；保留 `change / target / labels / rationale / evidence / cannot_infer`；参考端独立推理；处理缺图、无变化控制、错误编辑、指代损坏、人工语义评分需求和未执行知识编辑；把语义标签 `labels` 与抽样后的 `evaluation_labels` 分开。本轮逐条核对 109,599 判断的原语义哈希未变，R1–R4 合格判断集合全部保留，8×450 R5 抽样按原种子精确重放。

## 4. 五类需求如何落到五个 agent

| 分类／离线观察维度 | 功能定义 | agent 角色 | 当前采用实现与最有力证据 |
|---|---|---|---|
| R1 支持增加 | 新条件为某个具体判断增加支持；不必改变最终答案 | A1 Support establishment | 在规则覆盖内补入成立支持；与 A2 同次抽取、共享三值规则核。123 输入禁 add：69→43、71→48 正确 |
| R2 支持撤销 | 某条原有支持失效，同时检查其他支持是否仍成立 | A2 Support withdrawal | 撤销矛盾支持、保留有效独立路径和适用的 UNKNOWN 继承；禁 remove：69→53、71→60/123 |
| R3 候选重比 | 条件改变不同候选的相对支持 | A3 Candidate comparison | 公开 49 项目录、六排列、原骨干与原上下文、既有校正/读出；七系统 R3 均有净增，单次目录控制解释主要收益 |
| R4 后果推导 | 根据有依据的关系推导未直接给出的后果 | A4 Consequence execution | 完整给定模型/状态时执行局部干预；24 新 profile×12=288，两骨干全部数值正确；临床 v5 路由数为 0 |
| R5 目标保持 | 当前变化不应改变指定目标的判断 | A5 Judgment preservation | 已采用 F 的有效答案采样与任务适配共识；208 单元保持双正确加权分 60.19→65.90、59.17→66.47；16 新组另列 |

R1–R5 是离线、多标签评测维度；在线路由只读取当前合法题面、格式、规则/目录/模型可用能力，不能使用金标、R 标签、隐藏配对另一端或来源 ID 决策。五角色不是五套独立训练参数，也不保证一角色只作用于同编号 R 类。

**实际调用顺序：**诊断输入走 A3；否则规则资格输入走共享 A1/A2；否则完整给定模型走 A4；否则支持的普通/稳健性/关系题走 A5；其余原答案直通。完整 v5 每配置的分支数为目录 3,560、规则 123、A4 0、F 10,178、直通 44，总计 13,905。保留整个原生答案，A3/F 内部有候选聚合；不画成五人每题讨论后统一大模型仲裁。

原始研究追求过多专家证据聚合；121 输入上强旧 B 正确 87/82，含 A1 生成聚合 79/74，原生 ALL 70.27/64.41→63.06/54.05（74 单元）。这支持以已验证专门能力为基础采用稀疏协调。**CF-MoA 的贡献可以是操作分工、能力组合和可审计控制；当前证据不能宣称五个独立新 agent 的合作增量已经得到证明。**
