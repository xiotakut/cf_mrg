## 两种记录是什么意思

**文本比较单元**是一道题或一个官方对照组，可以是“原病例＋变体”、题内包含反事实假设的问题、一组干扰证据，或一次知识编辑。原题与必要参照保留对应关系，不额外算一条 CF。它不等于一个文件行或一个独立患者，也不表示各来源都能直接用相同的纯文本流程运行。

**缺图多模态元数据**是 2,497 个 MedMKEB 编辑记录：已取得编辑前后概念、相关测试和原作者图像路径，任务必需的图像尚未取得。可标注明确的文字子目标；需要图像的判断与编辑效果尚不能验证。这部分单列，不计入 25,746 个文本单元。

## R5 为什么多

文本中含 R5 的有 **20,318 个，占全部文本的 78.92%，占有标签文本的 93.65%**。这里统计任务要求“保持正确判断”，不是模型两次回答相同。

|标签|文本比较单元|
|---|---:|
|R1 新增支持|2,030|
|R2 撤销支持|88|
|R3 重新比较|389|
|R4 推导后果|53|
|R5 保持判断|20,318|

主要原因是来源构成：AMQA 的 4,164 个、MedRGB 的 3,680 个、MedPerturb 的 3,615 个，合计贡献文本 R5 的 56.40%。这些任务大量考察属性变化后的正确判断、抵抗错误证据，以及编辑后无关知识的保持。

当前抽样按来源规模：不足 1,000 全收，1,000–4,999 原则全收，达到 5,000 才取 2,500。因此 AMQA 的 4,806 个、MedPerturb 的 3,745 个、MedRGB 的 3,680 个均全留；这套规则没有实现来源等量或五类均衡。原始收集与冻结名单在本次发布中保持不变。

父标签是具体判断标签的并集。例如 MedCF 的无关知识保持子问标 R5，并不意味着主编辑也应保持旧答案；MedMKEB 的 2,496 个 R5 都来自文字 locality（无关知识保持），不能解读为图像判断保持。文本 R5 中 19,525 个仅有 R5，793 个还含其他标签，高占比主要来自数据组成。完整分母、来源贡献、题根和子判断统计见[统计口径与 R5 分布](reports/统计口径与R5分布.md)。

## 审核结论与使用范围

26 项候选及 2 项医学对照均找到第一手出处；实际取得内容来自其中 15 项。55,991 条完整记录、28,243 条分析记录及共享参照已与独立下载的官方原件逐值核对，未发现虚构 benchmark 或本项目捏造的原始记录。未取得的 11 项 CF 子集仍记录获取缺口。

分类结构检查覆盖全部分析集。语义审查采用逐项、分组及结构核验，审计抽查发现问题后扩查并修正 172 个判断，涉及 130 个单元；另保留 11 个不可靠或证据不足的原参考评分排除项。来源真实、标注有据与临床金标准可靠是分别记录的结论，本轮没有临床专家一致性验证。原题、原 gold、冻结名单及模型输出均未改写。

允许多标签，标签计数不能相加为独立题数。评分排除见具体判断表中的 `scoring_eligible=false`，仍存储的原任务得分不应解释为该子判断的有效准确率。不同任务保留原有评分，不汇总成一个跨任务总准确率。

## 读取与复核

下载 `.gz` 文件后解压即可读取 JSONL 或 CSV。也可以用 Python 标准库逐行读取；不要用 `splitlines()` 拆整个 JSONL 文本，原始证据可能包含 Unicode 行分隔字符。

```python
import gzip
import json

with gzip.open("data/analysis_annotations.jsonl.gz", "rt", encoding="utf-8") as f:
    for line in f:
        unit = json.loads(line)
        if "R2" in unit["labels"]:
            print(unit["unit_id"], unit["judgments"])
```

在本目录执行包内数量与对应关系检查：

```bash
python3 scripts/verify_github_results.py .
```

`scripts/audit_collection.py`、`audit_20260908/check_classification.py` 等保存原工作区的审核实现。重新运行完整来源审核需要官方原件、原题正文、冻结清单及原工作区依赖；本结果包自身的检查只验证发布内容的一致性，不重新证明来源真实性。审计记录中的本地绝对路径是历史定位信息，官方下载地址见 `sources/official_downloads.json`。
