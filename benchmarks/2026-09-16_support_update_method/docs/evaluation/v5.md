##### 5.1 机器与并行方式

本次机器有 4 张 NVIDIA H20，编号 **0–3，没有 GPU4**。每卡报告 97,871 MiB 总显存；`nvidia-smi` 的可用量还受驱动保留内存影响。“第 4 张卡”是 GPU3。显存份额、进程实际占用、整卡已用和整卡空闲是不同指标。

M3 的 8 个分片是题目集合，不是模型权重分片：每张卡部署完整 Qwen3-8B，各客户端向一个服务发送自己的题目。输入按初始 prompt token 数、item_id 排序后 `items[shard::8]` 分配，0–6 各 1,277 条，7 为 1,276 条。成员保存在plan.json（本地来源：`/home/data3/txy/Documents/Codex/2026-09-11/agent-md-medrgag-workspace-guide-md/results_v5_m3/plan.json`），整个运行没有修改这些原始 ID 集合。

“服务没有停”不等于“所有客户端都没有重启”。调度时仅停止待迁移的客户端，再在新服务上续跑；已有模型服务及未迁移分片继续。已保存结果和中间轮次保留；尚未落盘的在途阶段可能重算。最终零重复证明最终交付 ID 不重复，**不证明中途从未重复执行任何生成请求**。部分控制器的非零退出是这类人工交接产生的，不是模型无效答案或最终缺题。
