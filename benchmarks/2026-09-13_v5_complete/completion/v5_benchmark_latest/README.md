## 比较边界

各方法的骨干、检索语料及调用预算不同，分数差异不能全部归因于算法。新M4改变输出契约与允许采样token，M5未同步改变，因此新M4/M5不再是仅骨干不同的对照。M4的2048输出预算、温度0.7、top_p1、seed42、BF16、131072上下文及历史检索证据保持固定。

本v5已用于发现问题与选择M4修复方案，不能称为独立泛化确认。100条方案选择输入之外的13,805条，M4格式/原生有效率99.11%/79.39%；这些输入也不等同于独立来源病例验证集。开放诊断继续使用冻结归一化精确映射，无新同义词或模型裁判。分类成员基于evaluation_labels，原生准确率不是逐条分类理由的语义验证。
