## 判断与证据范围

| 层次 | 可核查内容 | 结论边界 |
|---|---|---|
| 材料与结构 | ID、字段、原生内容一致性、引用字面定位、来源路径、重复 | 文字存在不等于医学上支持关系 |
| 明确依据的功能关系 | 题内给定规则、明确条件变化、目标及作用范围 | 只能在可核实依据内判断；不把缺省当否定 |
| 外部医学知识 | 症状—疾病关系、目标相关性、临床参考正确性 | 缺专业依据则insufficient；模型不能自动提供临床金标 |

| 输出 | 填写要求 |
|---|---|
| R1–R5 | 每类yes/no/insufficient，可共现；支持不等于确诊，撤销一条依据不等于撤销全部支持 |
| 证据定位 | 指向当前/参照输入的字段path及原文quote；start/end为从0开始的Unicode字符位置，end不包含 |
| 关系说明 | 什么变化影响哪个具体目标，为什么 |
| 依据层级 | explicit_input题内明示；referenced_external本次实际核验的外部依据；needs_expertise尚缺专业依据 |
| 不能推出的结论 | 当前证据不能支持的扩大判断 |
| 待解决问题 | 目标不清、对照不足、医学关系待核实等 |

`validate_audit.py`仅验证JSON/schema、枚举和原文[start:end]是否等于quote；它不验证引用在医学上支持标签，也不自动核实外部文献。已生成120目标/600判断；1265次引文引用对应253个不同目标—字段—区间，字面定位全部通过，未估计分类准确率。

## 原第二阶段的处理

不再强制重判全部临床答案与参考可靠性，不推断不可观察的内部错误原因。沿用冻结原生评分，将“符合原参考”与“临床正确”分开。

可以单独记录有直接证据的格式无效、最终选项与参考不匹配、轨迹违反题内明确规则、提议与最终提交不一致。没有所需输出/轨迹则记不可观察。参考不匹配不等于已证实知识不足或某种认知错误。取消必做的类型×错误机制频率图，以类别表现、操作消融、修复/损害、保持/应变及适用覆盖支持主线。
