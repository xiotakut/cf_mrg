- [第二阶段：错误编码包](phase2_error_coding.zip)

## 人员与提交规则

由两名能理解这些医学任务与关系定义的复核者分别担任A、B。每人完成同一组120目标，只填自己的CSV，不查看另一人的答案，也不根据论文希望得到的结论作答。若已见过某些样例的旧分类、参考或方法身份，先告知协调者并记录接触范围，不把已知内容的复核冒充完全盲审。

请以UTF-8导入和保存CSV。保留表头、`blind_id`、`reviewer_id`以及全部120行；不要排序后错位、删除疑难样例或把多行证据拆成新记录。先保存不可覆盖的原始提交副本，之后的补充或裁决另存。两人可以共享一般定义说明，不能在独立提交前讨论这120题的具体标签。

## 第一阶段：对“变化—具体判断”分类

先读包内`instructions.txt`。每题依次看判断目标、比较轴、参照输入（如有）和当前输入。分类对象是这次变化对这个具体目标的功能关系，**不是病例整体，也不是最终答案是否改变**。

| 字段 | 填写内容 |
|---|---|
| `target_clear` | `yes / no / uncertain`：判断目标是否清楚 |
| `comparison_sufficient` | `yes / no / uncertain`：参照与当前条件是否足以比较 |
| `R1`—`R5` | 每列分别填`yes / no / insufficient`；允许多标签 |
| `evidence_quotes` | 支持判断的短原文引用，说明来自参照还是当前输入 |
| `relation_rationale` | 用一两句话连接“什么变化→影响哪个目标→为何属于/不属于该关系” |
| `cannot_infer` | 当前材料不能推出的结论，避免扩大目标或把缺省当否定 |
| `missing_evidence` | 缺少的规则、比较条件或医学依据；外部一般医学资料写具体来源 |
| `alternative_target` | 原目标模糊/错绑时提出候选目标；不要直接替换原目标后照常打标签 |
| `notes` | 其他分歧、既有接触或无法判断的原因 |

五类简要定义：

| 类别 | 判断问题 |
|---|---|
| R1 新增支持 | 变化是否为该目标增加了原先没有的依据？ |
| R2 撤销支持 | 原本支持该目标的条件是否明确失效？其他独立支持可以仍然成立。 |
| R3 重新比较 | 至少两个候选的相对依据是否发生变化？ |
| R4 推导后果 | 是否要基于改变的前提，推导题中尚未直接给出的结果？ |
| R5 保持判断 | 是否有理由认定该变化不应影响这个具体目标？ |

新增文字不自动等于R1；删除描述不自动等于R2；答案相同不自动等于R5；答案翻转也不意味着R1/R2/R3都成立。可以多类yes，也可以全部insufficient。没有外部参照的题，不自行猜一个“原病例”；按题内对照判断，缺少必要比较时如实记不足。可以查一般医学规则，但不要检索这些样例的旧分类、模型结果或论文结论。

A、B分别提交`phase1_A.csv`和`phase1_B.csv`。协调者检查编号齐全、枚举值和证据栏，再冻结原始表。此时不能先协商成统一答案再计算一致性。

## 第二阶段：对匿名回答编码可观察错误

第一阶段两份表冻结后，发第二包。相同T编号现在增加一份匿名历史回答和原任务参考。参考可被质疑；回答可能正确，也可能无效。先独立填写：

| 字段 | 允许值及含义 |
|---|---|
| `answer_status` | `correct / incorrect / unavailable / uncertain` |
| `reference_reliable` | `yes / no / uncertain`；与参考不一致不自动是模型错 |
| `target_alignment` | `aligned / partial / not_observable`；原生回答是否能观察到第一阶段目标 |
| 后续错误字段 | 分别填`yes / no / uncertain`，可多选，不强行归到功能类 |
| `insufficient_evidence` | `yes / no / uncertain`，并在证据或备注里说明缺什么 |
| `evidence_quotes`、`notes` | 引用具体输入/输出，说明问题及判断边界 |

错误字段含义：`support_omitted`为遗漏已成立支持；`invalid_support_retained`为仍使用失效支持；`over_retraction`为误删仍成立的独立支持；`candidate_decision_error`为可观察的候选/最终决策错误；`intervention_execution_error`为干预与后果计算不一致；`irrelevant_change_response`为对目标无关变化作出不当响应；另保留`knowledge_gap`、`format_or_mapping_problem`、`other_error`。

不要仅凭答错推测模型内部机制，也不要因解释提到某关系就认定正确执行。若需要另一端的模型回答而材料没有提供，标证据不足，不猜测。正确回答不强制编码一个错误；无法判定时用uncertain并写原因。

A、B分别提交`phase2_A.csv`和`phase2_B.csv`。两阶段总共收到四份独立表。提交文件应私下交给协调者，不要在公开仓库Issue/评论中逐题讨论，以免污染其他复核者。

## 后续统计与裁决

收到原始独立表后，先报告裁决前一致性：各类共同可判定目标上的Cohen kappa、正标签一致率；同时在完整120目标上报告证据不足和分歧，多标签完全一致率/Jaccard作补充。证据不足不偷偷记成no，也不从总数中消失。少样本和高度不平衡类别单独解释。

之后再讨论分歧，必要时由第三人裁决，保存两份原始判断、裁决结果及理由。第二阶段同样保留独立编码，再汇总类型×可观察错误，并分别标明参考不可靠、目标不可观察和证据不足。本材料采用分层抽样，不能用其类别占比估计真实任务中的自然比例。

上传材料不代表人工复核已经开始或完成；不得由模型填写后冒充两名独立人工。
