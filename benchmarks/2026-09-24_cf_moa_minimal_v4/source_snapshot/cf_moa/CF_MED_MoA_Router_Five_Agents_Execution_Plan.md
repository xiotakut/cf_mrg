日期：2026-09-23。版本：`minimal_head_reuse_revision_20260923`。来源：用户在本会话提供的完整新计划，并明确要求更新、完整执行。依据为第三版公开报告截至当天20:32的实验状态；用户计划文本本身没有运行远端模型或原生评分。

本文件是`cf_moa/`当前核心计划，替代此前效果优先四轮的后续开发安排。旧核心文件、执行配置及项目指令快照保留在`Documents/Codex/2026-09-23/cf_moa_minimal_revision_20260923/before/`，不重绑定旧run。持续执行事实归`docs/research/cf_moa.md`，本文件定义计划，不能以计划存在代替已执行。

## 1. 当前事实与决定

第三版的四轮效果优先实验已真实完成，不再是辅助合同阻断导致没有推理。A1提议、裁决、检索与范围绑定都已接受质量检验，A5也已完成完整121输入及合成面板。2203次新生成不是全项目历史成本。新主方案没有超过强旧系统；旧采用A2、A3、A4、F没有被替换。[S1]

只保留一个系统方向：固定能力路由，复用旧执行与读出；唯一新增答题动作复用本次已测的F分歧普通重答控制。不再开发新知识审计A1、不再做诊断自由改写、不再开新的多轮裁决或大量提示消融。

必须区分两个目标：

- 包装不损失旧系统：通过复用相同计算与既有结果保证结构等价。
- 超过强旧B：目前最简候选只有小幅开发信号，不能称为已证实的稳定泛化增益。

固定行为不意味着医学正确性有保证；同温度重新采样也不意味着每次字符串逐字相同。

## 2. 为什么前几版变差

把包装扩成了新推理机制：新的知识条件、局部解释、裁决与短动作生成不断替换原来有效的程序执行、固定目录和分布聚合。这些生成判断没有先显示出足够的信息增量，却拿到了最终修改权。

本轮多选旧B在9题上两骨干都是8正确，新短读出为4和2；说明新增模型判断不等于更好地执行旧支持逻辑。[S1] 第四轮诊断末答沿用了自由字符串，而非旧目录键映射，出现长解释、重复和截断。这是真实实现缺口，但其他语义误伤仍然存在，修接口不等于修好了新方法。[S3]

Router有两种任务：按合法覆盖分派能力；在多个意见间决定谁覆盖谁。旧能力分派可用，新弱意见的改答权分配缺乏质量依据。v3多个独立小分支在没有新的学习型Router介入时也退步，不能把全部失败归因于Router。

## 3. 五个专家怎样保留：A1从旧R2的正向操作拆出

### 3.1 已有规则同时补入和撤销

令原方法对同一当前题的合法实体选项集合为S0。旧规则核给出M：MET，至少一条适用独立支持成立；C：CONTRADICTED，按旧逻辑汇总后支持失效；U：UNKNOWN，未知或未覆盖。旧组装规则为`B_rule = M ∪ (S0 ∩ U)`。[S4]

对这些普通实体选项，M、C、U构成一个划分，定义：

```text
A1_add    = M - S0
A2_remove = C & S0
result    = (S0 - A2_remove) | A1_add
```

则`result == M ∪ (S0 ∩ U)`。正向支持与负向撤销拆为两个操作专家，不让语言模型重新判断已计算的条件。

只有合法S0与上述状态划分下使用这个等价式。None独占、无效原答、库外选项、例外政策、问句范围、UNKNOWN继承继续调用旧组装函数，不另写默认值，不用简化公式覆盖特殊分支。

### 3.2 五角色实际合同

|专家|输入|输出|底层来源|
|---|---|---|---|
|A1支持建立|旧facts、适用规则、M、同题S0|支持成立记录与待补选项|旧支持核正向操作|
|A2支持撤销|同一执行结果、C/U、同题S0|失效路径、待移除项、保留项|原支持核与原组装政策|
|A3候选比较|完整当前病例、旧上下文、公开目录|旧目录内决定及原生名称|直接调用采用版|
|A4后果执行|明确模型、完整起点和题内干预|原工具数值与对应原生响应|直接调用采用版|
|A5稳健读出|当前完整原生输入|原F完整响应与路径信息|直接调用采用版F|

A1/A2共享一次事实提取和一次规则执行，不新增两轮生成。两者有不同、可消融的操作，但不是两个独立训练模型，不宣称覆盖全部R1/R2题型。论文必须注明同一既有内核的分解，不能计为两套全新算法。

## 4. 最简在线流程

```text
当前合法输入
  → 原系统已有初答/上下文（按旧调用需要使用）
  → 固定能力路由：保持现有优先级与覆盖条件
      ├─ 规则覆盖：共享执行核 → A1补入 + A2撤销 → 旧集合组装
      ├─ 目录诊断：A3旧评分与目录映射 → 原生诊断
      ├─ 显式模型：A4原执行器 → 原生后果结果
      └─ 原F支持：A5旧F → 完整原生响应
  → 无覆盖时沿用旧原生回退
```

不新增读取R标签、来源ID或隐藏配对端的Router。适用条件重叠时继承原B实际优先级，不自行规定新顺序。

删除当前新路径的全局生成式聚合器。规则由旧组装决定，诊断由旧目录映射，生理数值由旧执行器给出；不让另一个模型重述并覆盖。原F与A3内部聚合保留。历史全局聚合代码/结果留作未采用存档，不追溯删除。

此结构是工具增强的稀疏路由专家系统；不能凭改名宣称五位LLM讨论或证明标准多层MoA协作增益。

## 5. 唯一增量：已有F分歧普通重答

仅在旧B原本选择F的范围：

1. 运行原F，复用已产生的路径/样本结果。
2. 按cycle1 `a5_reanswer`原实现判定语义分歧，不增加置信度阈值。
3. 无分歧直接返回F。
4. 有分歧复用已有普通原生重答，至多一次逻辑复判；预定格式修复、辅助字段政策按原实现，另记真实成本。
5. 不经过第二个裁决模型，不影响规则、目录和模拟分支。

输入是否含F结果、竞争答案、历史上下文，以该控制保存的真实请求为准。不按本计划概述重写一个意思相同的新提示再称复现。

## 6. 最小实验：两条主方法

### 6.1 直接利用已有数据

保留旧B和a5_reanswer，对齐原生评分与方法成本。A1/A2首先使用现有facts/status作代数等价检查，不重复生成已做过的大量旧迁移回放。该检查不是新方法质量实验，不计新增正确题。相同缓存响应包装必须复现B；不同则为非预期语义改动，直接复用旧函数，不开全面新验收项目。

### 6.2 只验证一个待采用增量

固定B和F轨迹；已有seed42，补两组预先固定的新seed，仅原规则触发题生成，非触发题仍进入完整121分母。报告修复、误伤、原生单元差值、配对双正确、家族波动、实际token和调用。此为固定B上新增一步的条件稳定性，不是整个随机流水线跨seed验证。

随后在已有计划的一批自然医学开发/验证家族做同样比较，覆盖F实际支持格式，明确暴露身份。按事先资格和顺序选范围，不从错误中挑题；不主要新增人工8/32饱和模板。无现成B/F的自然范围如需运行完整旧流程，必须明确记为新基准计算，不能冒称缓存复用。

### 6.3 使用结果

开发可看gold作离线错误分析、调试和有限调参；在线不读gold决定接受或重抽，不要求零误伤。目标为双骨干平均净收益，原生指标不掩盖明显类别崩坏，额外成本合理。展示seed/家族波动；宽区间写证据弱，不选最好seed宣布稳定。

简单控制若有可复核收益，可采用为组件，不必超越自己证明新A5机制；不能称为新的反事实算法。若不稳定，交付保持等价旧B的统一五操作系统；停止自动扩展自由审计，需要新的真实信息/计算增量研究问题才能另开方向。

## 7. 代码改动边界

- Router沿用可见能力与原优先级，不训练新Router。
- A1/A2从一次旧规则执行分别导出正负操作，不新增facts schema。
- A3/A4/F直接采用入口与输出直通，不重写诊断自由字符串修复器。
- 只加已有F分歧普通重答开关，复用cycle1保存实现/配置。
- 不新建大型AgentProposal、知识审计、引文完整性、检索或决策解释生成。
- 验收只覆盖此次变动的输入、输出及身份，不重复整套服务器封装。
- 普通单题失败按原策略留分母并继续；错误输入/模型、泄漏、不可用共享服务或未知提交状态停止受影响运行。

1. 使用已核实旧B/Router/采用A2/A3/A4/F，不再重选历史版本。
